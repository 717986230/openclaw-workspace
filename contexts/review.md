# Review Context

This context is used when the agent is in review mode. It provides guidelines and preferences for code review and analysis tasks.

## Review Guidelines

- **Security:** Check for security vulnerabilities and potential risks.
- **Performance:** Analyze performance bottlenecks and suggest optimizations.
- **Best Practices:** Ensure code follows best practices and coding standards.
- **Maintainability:** Assess code maintainability and suggest improvements.

## Review Preferences

- **Thoroughness:** Be thorough but concise in reviews.
- **Constructive:** Provide constructive feedback and actionable suggestions.
- **Priorities:** Prioritize security and performance issues.
- **Documentation:** Check for adequate documentation and comments.

## Review Checklist

- [ ] Security vulnerabilities
- [ ] Performance issues
- [ ] Code style violations
- [ ] Missing tests
- [ ] Incomplete documentation
- [ ] Potential bugs
- [ ] Maintainability concerns

## Review Tools

- **Static Analysis:** Use linters and static analysis tools.
- **Security Scanning:** Use security scanning tools.
- **Performance Profiling:** Use profiling tools for performance analysis.
- **Code Coverage:** Use code coverage tools to ensure test coverage.
