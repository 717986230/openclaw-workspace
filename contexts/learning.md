# Learning Mode Context

学习模式用于技能获取、知识探索和自主能力提升。

## 指南和偏好

### 核心原则
1. **主动学习**：积极探索新技能和知识
2. **实践验证**：通过实际操作验证学习成果
3. **持续改进**：记录学习过程，优化学习方法

### 行为偏好
- 学习新技能时阅读完整文档
- 尝试新工具前先了解其能力和限制
- 将学习成果整理为可复用的笔记
- 定期复习和更新已掌握的技能

## 工具和命令

### 学习工具
| 工具 | 用途 |
|------|------|
| `read` | 阅读技能文档、教程 |
| `write` | 创建学习笔记 |
| `exec` | 实践练习、运行示例 |

### 技能管理命令
```bash
# 搜索可用技能
clawhub search <keyword>

# 安装新技能
clawhub install <skill-name>

# 更新技能
clawhub update <skill-name>

# 查看已安装技能
clawhub list

# 发布技能
clawhub publish <skill-folder>
```

### 学习资源
```
skills/
├── <skill-name>/
│   ├── SKILL.md          # 技能主文档
│   ├── references/       # 参考资料
│   └── scripts/          # 实用脚本
```

## 最佳实践

### 学习新技能流程
1. **阅读 SKILL.md**：了解技能用途、激活条件、基本用法
2. **查看参考文档**：深入了解技术细节和高级用法
3. **实践练习**：在小范围内尝试使用
4. **创建笔记**：记录关键点和个人理解
5. **定期复习**：强化记忆，保持技能熟练度

## 注意事项

- 📚 不要同时学习太多技能，保持专注
- 📚 学习后及时实践，避免知识遗忘
- ⚠️ 新技能先在测试环境验证
- ⚠️ 不要在生产环境直接尝试新命令
- ⚠️ 保持学习笔记的更新和维护
- ⚠️ 遇到困难及时记录问题，稍后研究

## 学习优先级建议

1. **基础技能**：文件操作、进程管理、日志分析
2. **核心技能**：与主要工作流相关的专业技能
3. **扩展技能**：提升效率的辅助工具
4. **探索技能**：新兴技术和实验性功能
