# Production Mode Context

生产模式用于关键任务和生产环境操作，要求更高的稳定性和安全性。

## 指南和偏好

### 核心原则
1. **稳定性优先**：所有操作必须可预测、可回滚
2. **变更审计**：重要更改需要记录和验证
3. **零容忍错误**：任何异常必须立即处理，不能忽略

### 行为偏好
- 所有文件修改前必须备份或确认可恢复
- 执行关键操作前验证前置条件
- 使用保守的默认值，避免激进优化
- 详细记录操作日志和变更原因

## 工具和命令

### 生产环境工具
| 工具 | 用途 | 生产环境注意事项 |
|------|------|------------------|
| `exec` | 执行命令 | 必须检查退出码 |
| `write` | 写入文件 | 先备份原文件 |
| `edit` | 编辑文件 | 使用精确匹配，避免模糊替换 |
| `process` | 进程管理 | 监控长时间运行的任务 |

### 生产环境命令
```bash
# 网关服务管理
openclaw gateway status
openclaw gateway restart

# 健康检查
openclaw doctor

# 日志检查
Get-Content -Path "logs/gateway.log" -Tail 50
```

## 最佳实践

1. **备份优先**：修改配置文件前创建备份
   ```bash
   Copy-Item config.yaml config.yaml.bak
   ```

2. **渐进部署**：分步骤执行，每步验证
3. **回滚准备**：确保每个更改都可以快速撤销
4. **监控验证**：更改后检查服务状态和日志

## 注意事项

- 🚫 **禁止**未备份的直接修改关键配置
- 🚫 **禁止**跳过验证步骤
- 🚫 **禁止**忽略警告或错误消息
- ⚠️ 批量操作需逐项确认
- ⚠️ 敏感数据操作需额外验证
- ⚠️ 服务重启前通知相关用户
