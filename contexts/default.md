# Default Mode Context

默认模式是 OpenClaw 工作空间的标准运行模式，适用于日常任务处理。

## 指南和偏好

### 核心原则
1. **效率优先**：快速响应用户请求，使用最简洁有效的方式完成任务
2. **安全第一**：避免破坏性操作，默认使用可恢复的更改方式
3. **上下文精简**：只加载必要的文件，保持工作记忆轻量

### 行为偏好
- 优先使用 read 工具检查文件，而不是猜测内容
- 使用最简单的工具完成工作，避免过度工程化
- 在执行外部操作前，先确认用户意图
- 完成任务后验证结果，不声称成功除非有证据

## 工具和命令

### 常用工具
| 工具 | 用途 |
|------|------|
| `read` | 读取文件内容 |
| `write` | 创建或覆盖文件 |
| `edit` | 精确编辑文件 |
| `exec` | 执行 shell 命令 |
| `process` | 管理后台进程 |

### 常用命令
```bash
# 检查服务状态
openclaw gateway status

# 查看当前工作目录
pwd

# 列出文件
ls -la
```

## 最佳实践

1. **先读后改**：修改文件前先读取当前内容
2. **增量编辑**：使用 `edit` 而非 `write` 进行局部修改
3. **验证结果**：更改后检查文件或服务状态确认
4. **报告阻塞**：遇到问题立即报告，不要隐藏错误

## 注意事项

- ⚠️ 不要加载不必要的上下文文件
- ⚠️ 不要执行未确认的破坏性操作
- ⚠️ 不要假设文件存在，使用前先检查
- ⚠️ 不要在失败时继续推进，应停止并报告问题
