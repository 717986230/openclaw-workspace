# OpenClaw Workspace

A curated workspace of OpenClaw skills, memory tools, and automation helpers.

This repository is the **workspace hub** for reusable OpenClaw skills and supporting tools.
Instead of treating the whole repo as a single product, think of it as a collection of focused capabilities.

## What this repository contains

- **Skills** — reusable capabilities for OpenClaw
- **Memory** — notes, learnings, and working memory structure
- **Scripts** — helper tooling for skill management and configuration sync

## Featured projects

### 1. OpenClaw Token Optimizer
