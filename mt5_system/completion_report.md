### 核心功能

1. **因子分析**: 10类因子，综合评分
2. **多时间框架**: M1/M5/M15/M30/H1/H4/D1/W1
3. **参数优化**: 遗传算法自动优化
4. **品种筛选**: 流动性/波动率/趋势/相关性
5. **时间过滤**: 交易时段/新闻/低流动性过滤
6. **ML预测**: 规则+机器学习集成
7. **信号集成**: 综合多来源信号

## 使用方法

### 快速开始

```bash
# 1. 安装依赖
pip install pandas numpy flask flask-socketio MetaTrader5

# 2. 运行测试
python mt5_system/test_all.py

# 3. 启动系统 (需要 MT5 终端)
python mt5_system/run.py
```

### Windows 快速启动

```bash
# 双击运行
mt5_system/start_v2.bat
```

### 配置

编辑 `mt5_system/config.py` 配置:
- MT5 账户信息
- 交易品种
- 风险管理参数
- 技术指标参数
