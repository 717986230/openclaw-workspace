## 🔧 安装步骤

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 2. 安装 MetaTrader5 Python 库

```bash
pip install MetaTrader5
```

### 3. 配置 MT5

1. 打开 MetaTrader 5 终端
2. 启用 "允许算法交易"
3. 启用 "允许 DLL 导入"
4. 记录账号、密码、服务器信息

### 4. 配置系统

编辑 `config.py` 文件，配置以下参数：

```python
# MT5 连接配置
MT5_CONFIG = {
    'login': '你的账号',
    'password': '你的密码',
    'server': '你的服务器',
    'path': 'MT5终端路径',
}

# 交易品种配置
SYMBOLS_CONFIG = {
    'enabled': [
        'EURUSD',
        'GBPUSD',
        'USDJPY',
        'XAUUSD',
        'XAGUSD',
    ],
}

# 风险管理配置
RISK_CONFIG = {
    'max_position_size': 0.02,  # 最大仓位比例
    'max_daily_loss': 0.05,  # 最大日亏损比例
    'max_drawdown': 0.15,  # 最大回撤比例
    'risk_reward_ratio': 2.0,  # 风险收益比
    'max_positions': 5,  # 最大持仓数
}
```

## 🔍 技术指标说明

### 移动平均线 (MA)
- **SMA**: 简单移动平均线
- **EMA**: 指数移动平均线
- 用途: 趋势判断、支撑阻力位

### 相对强弱指标 (RSI)
- **范围**: 0-100
- **超买**: > 70
- **超卖**: < 30
- 用途: 超买超卖判断

### MACD 指标
- **MACD 线**: 快线 - 慢线
- **Signal 线**: MACD 的移动平均
- **Histogram**: MACD - Signal
- 用途: 趋势跟踪、买卖信号

### 布林带 (Bollinger Bands)
- **上轨**: SMA + 2 × 标准差
- **中轨**: SMA
- **下轨**: SMA - 2 × 标准差
- 用途: 波动性分析、超买超卖

### 平均真实波幅 (ATR)
- **计算**: 真实波幅的移动平均
- 用途: 止损设置、波动性分析
