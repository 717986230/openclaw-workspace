**Location**: `memory/database/retrieval_strategies.py`

Four retrieval strategies:
1. **Attribution Retrieval** (按需归因检索) - Query by Entity/Process/Session layers
2. **Time Decay Retrieval** (时间衰减检索) - Recent memories weighted higher, exponential decay
3. **Importance Priority Retrieval** (重要性优先检索) - Prioritize high-importance memories
4. **Vector Semantic Retrieval** (向量语义检索) - LanceDB similarity search

Smart retrieval modes:
- `balanced` - All four strategies balanced
- `importance` - Importance-first
- `recent` - Recency-first
- `semantic` - Semantic-first
