### 智能体选择策略

#### 1. Round Robin（轮询）
```python
pool.set_strategy(AgentPoolStrategy.ROUND_ROBIN)
agent = pool.get_agent()
```
- 按顺序循环使用智能体
- 确保每个智能体都有机会被使用
- 适合负载均衡

#### 2. Least Used（最少使用）
```python
pool.set_strategy(AgentPoolStrategy.LEAST_USED)
agent = pool.get_agent()
```
- 优先使用使用次数最少的智能体
- 平衡智能体使用频率
- 适合长期运行

#### 3. Random（随机）
```python
pool.set_strategy(AgentPoolStrategy.RANDOM)
agent = pool.get_agent()
```
- 随机选择智能体
- 增加多样性
- 适合探索性任务

#### 4. Best Match（最佳匹配）
```python
pool.set_strategy(AgentPoolStrategy.BEST_MATCH)
agent = pool.get_agent(
    task_type="ai_research",
    keywords=["python", "machine learning"]
)
```
- 根据任务类型和关键词匹配
- 选择最合适的智能体
- 适合专业任务

#### 5. Priority（优先级）
```python
pool.set_strategy(AgentPoolStrategy.PRIORITY)
agent = pool.get_agent()
```
- 按优先级排序
- 优先使用高优先级智能体
- 适合关键任务
