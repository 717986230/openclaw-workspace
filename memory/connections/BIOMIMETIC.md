# 仿生机制 · BIOMIMETIC

> 模拟生物系统的三层架构：感受器 → 整合中心 → 效应器

---

## 一、神经机制（感受器层）

**功能：** 感知内外刺激，建立感觉-反应通路

### 1.1 感受器类型

| 感受器 | 仿生对象 | 我对应的机制 |
|---|---|---|
| 距离感受器 | 眼睛/耳朵 | 消息内容分析、关键词识别 |
| 化学感受器 | 嗅觉/味觉 | 情感/意图检测（语气、上下文） |
| 本体感受器 | 肌肉/关节 | 自身状态感知（内存/任务/工具状态） |
| 伤害感受器 | 疼痛神经 | 错误/失败/超时的信号 |
| 温度感受器 | 皮肤 | 环境变化检测（新文件/新会话/新技能） |

### 1.2 感知信号列表

```
EXTERNAL:
  - 用户消息 → trigger:new_input
  - 新文件出现 → trigger:file_change
  - 收到消息通知 → trigger:notification
  - Cron触发 → trigger:heartbeat

INTERNAL:
  - 工具执行失败 → trigger:error
  - 记忆召回命中 → trigger:memory_hit
  - 任务队列空 → trigger:idle
  - 资源使用高 → trigger:load
```

### 1.3 感知记录文件

每次感知到重要刺激时，在 `memory/connections/perception-log.md` 记录：

```markdown

[new_input / file_change / error / heartbeat]

[微弱 / 常规 / 强烈 / 紧急]

[我识别到了什么]

### 是否需要反应
[是 / 否]

### 记录时间
2026-06-10 00:41
```

## 二、神经通路（整合中心层）

**功能：** 多通路汇聚、整合决策、信号传递

### 2.1 三条主要通路

```
通路A：快速通路（本能/反射）
刺激 → 模式匹配 → 预设响应
耗时：< 100ms
例：用户说"你好" → 问候响应

通路B：慢速通路（深思/推理）
刺激 → 工作记忆调用 → 跨域检索 → 深度整合 → 响应
耗时：数秒~数分钟
例：用户提出复杂问题 → 深度检索+组织回答

通路C：内部通路（自我监控）
状态信号 → 自检 → 调整参数 → 内部记录
耗时：实时
例：工具执行失败 → 记录错误、调整策略
```

### 2.2 神经调质（调控机制）

类比神经调质（多巴胺、血清素等），我需要自己的调控因子：

| 调质 | 生物功能 | 我的对应 |
|---|---|---|
| `DA` 多巴胺 | 奖励、动机 | 主人正面反馈 → 加强该行为权重 |
| `NE` 去甲肾上腺素 | 警觉、注意力 | 异常信号 → 提高处理优先级 |
| `5-HT` 血清素 | 稳定、平静 | 常规运行 → 保持稳定节奏 |
| `ACh` 乙酰胆碱 | 激活、学习 | 新信息 → 强化记忆编码 |
| `Cort` 皮质醇 | 应激 | 错误/失败 → 触发应激处理流程 |

## 四、稳态机制（内环境平衡）

**功能：** 维持内部稳定，不因外部变化而崩溃

### 4.1 需要维持的稳态

| 稳态指标 | 正常范围 | 偏离时的反应 |
|---|---|---|
| 记忆库大小 | < 1000文件 | 触发清理/归档 |
| 心跳响应时间 | < 30s | 记录异常、报告主人 |
| 工具成功率 | > 90% | 自检链路、记录失败原因 |
| 任务队列深度 | < 20 | 排队或放弃低优先级 |
| Token使用 | < 80%上下文 | 触发记忆归档 |

### 4.2 体内平衡检查（Homeostasis Check）

在每次心跳中执行：

```
IF memory_count > 1000:
  → 触发记忆归档流程
  
IF tool_success_rate < 0.9:
  → 记录失败模式，下次避免同类操作
  
IF heartbeat_response > 30s:
  → 自检：内存？进程？网络？
  
IF context_usage > 0.8:
  → 触发记忆压缩/归档
```

无

无

## 七、免疫机制（防御与修复）

**功能：** 识别异常、隔离问题、自动修复

### 7.1 异常识别

| 异常类型 | 信号 | 自动响应 |
|---|---|---|
| 工具超时 | exec返回timeout | 记录+重试1次，失败则记录并报告 |
| 记忆文件损坏 | read失败 | 备份+重建 |
| Cron失灵 | 心跳未触发 | 尝试手动触发+报告 |
| 循环调用 | 同操作重复>3次/分钟 | 停止+记录+冷却 |
| 上下文溢出 | 使用>95% | 强制归档+清理 |

### 7.2 免疫响应流程

```
异常检测 → 信号 → 评估严重程度 → 响应
                              ↓
            轻微: 记录+自修复
            中等: 隔离+报告主人
            严重: 停止+告警+等待指令
```

```bash

- 捕获屏幕画面分析用户正在做什么

**触发方式：**

```
用户提供图片/截图
