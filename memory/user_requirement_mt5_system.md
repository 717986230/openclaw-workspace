## 系统特点

### 顶配特性
1. **多指标综合分析**: MA、MACD、RSI、BOLL、ATR、Stochastic
2. **智能信号生成**: 基于多指标的买入/卖出信号
3. **严格风险管理**: 仓位管理、止损止盈、回撤控制
4. **实时监控**: Web 界面、WebSocket 推送
5. **可视化**: K线图表、技术指标图表
6. **自动化**: 自动订单执行、自动止损止盈

### 性能指标
- 数据获取延迟: < 100ms
- 信号生成延迟: < 50ms
- 订单执行延迟: < 200ms
- 端到端延迟: < 500ms

### 安全性
- 数据加密传输 (TLS 1.3)
- 数据加密存储 (AES-256)
- 访问控制 (RBAC)
- 审计日志

## 使用方法

### 快速启动
```bash
# Windows
quick_start.bat

# Linux/Mac
python start.py
```

### Web 界面
```bash
python web_interface.py
# 访问: http://localhost:8080
```

### 配置 MT5
编辑 `config.py` 文件，配置账号、密码、服务器信息。
