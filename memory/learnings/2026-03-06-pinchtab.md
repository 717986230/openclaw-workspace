## 核心要点

### Pinchtab 是什么？
- 一个仅 12MB 的二进制文件
- 让任何 AI Agent 完全自动化控制浏览器
- 不限开发语言、不绑定任何 SDK
- 甚至通过 curl 都能直接调用

---

## 对比 OpenClaw / Playwright 的优势

### 1. 零配置
- 丢进去就能跑
- 直接接管本地 Chrome

### 2. 省钱神器 💰
- 传统截图方案：一个页面可能消耗 1 万个 Tokens
- Pinchtab：只要 800 Tokens
- **成本直接砍掉 13 倍！**

### 3. 隐身潜行 🥷
- 自带 stealth mode
- 主流网站的反爬策略基本是摆设

### 4. 智能 Diff
- 每次只返回变化的内容
- Agent 不用反复读废话

---

## 技术细节

- **文件大小：** 仅 12MB
- **调用方式：** HTTP API（curl 可直接调用）
- **GitHub：** https://github.com/pinchtab/pinchtab

## 适用场景

- 做全自动网页操作 Agent
- 需要低成本浏览器控制的项目
- 需要绕过反爬策略的场景
- Token 预算有限的项目
