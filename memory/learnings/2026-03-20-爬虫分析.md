# 爬虫学习：fetch_morning_news.py 分析

## 脚本功能
- 每日06:00自动运行
- 抓取全球新闻RSS → JSON
- 覆盖：政治、军事、经济、AI大模型

## 爬虫架构

### 数据源（RSS）
| 分类 | 来源 |
|------|------|
| 政治 | BBC, Reuters, AP |
| 军事 | Defense News |
| 经济 | Reuters Business, CNBC |
| AI大模型 | Hacker News, VentureBeat, MIT Tech |

### 核心函数
- `curl_rss()` — 用curl抓取，支持UA伪装
- `_safe_parse_xml()` — 防XXE攻击
- `parse_rss()` — XML解析为结构化数据
- `match_category()` — 关键词分类
- `fetch_category()` — 按分类抓取

### 反爬措施
- ✅ UA伪装：'Mozilla/5.0 (compatible; MorningBrief/1.0)'
- ✅ XXE防护：剥离DOCTYPE/ENTITY
- ✅ 大小限制：max_size=5MB
- ✅ 超时控制：timeout=10s

## 技术要点

### curl vs requests
- 用subprocess调用curl而非Python requests
- 优点：curl更稳定，兼容性更好
- 缺点：需要系统安装curl

### RSS vs HTML
- RSS是结构化数据，解析简单
- 不需要BeautifulSoup，直接XML解析

## 学习路径建议
1. **入门**：RSS爬虫（简单，结构化）
2. **进阶**：HTML爬虫（requests + BeautifulSoup）
3. **高级**：JS渲染页（Playwright/Selenium）
