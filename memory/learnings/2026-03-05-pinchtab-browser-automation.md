## 什么是 Pinchtab？

一个仅 **12MB** 的二进制文件，可以让任何 AI Agent 完全自动化控制浏览器！

---

## 核心优势

### 1. 不限开发语言，不绑定任何 SDK
- 甚至通过 curl 都能直接调用！
- 零配置：丢进去就能跑，直接接管本地 Chrome

### 2. 省钱神器！
- 传统的截图方案一个页面可能消耗 **1 万个 Tokens**
- 而 Pinchtab 只要 **800 Tokens**
- **成本直接砍掉 13 倍！**

### 3. 隐身潜行（Stealth Mode）
- 自带 stealth mode
- 主流网站的反爬策略在它面前基本是摆设

### 4. 智能 Diff
- 每次只返回变化的内容
- Agent 不用反复读废话
