# 《工程控制论》章节笔记

## 第一章 绪论、系统与线性系统

### 核心概念
- **工程控制论定义**：研究控制与引导系统的工程科学，关注具有直接工程应用的控制论部分
- **系统概念**：由相互关联的组件组成的整体，具有特定功能
- **线性系统**：满足叠加原理的系统，输出与输入成线性关系

### 关键理论
1. **系统建模**
   - 数学描述：微分方程、传递函数
   - 状态空间表示
   - 输入-输出关系

2. **线性系统特性**
   - 叠加性：f(x₁ + x₂) = f(x₁) + f(x₂)
   - 齐次性：f(ax) = af(x)
   - 时不变性：系统参数不随时间变化

3. **系统分类**
   - 连续系统 vs 离散系统
   - 时变系统 vs 时不变系统
   - 确定性系统 vs 随机系统

### 工程应用
- 自动控制系统设计
- 信号处理
- 通信系统

## 第二章 拉氏变换法、拉氏变换与常微分方程

### 核心概念
- **拉氏变换**：将时域函数转换为复频域函数的数学工具
- **变换性质**：线性、微分、积分、时移等

### 关键理论
1. **拉氏变换定义**
   ```
   L{f(t)} = F(s) = ∫₀^∞ f(t)e^(-st)dt
   ```

2. **基本变换对**
   - 单位阶跃：1 → 1/s
   - 指数函数：e^(at) → 1/(s-a)
   - 正弦函数：sin(ωt) → ω/(s²+ω²)

3. **微分方程求解**
   - 将微分方程转换为代数方程
   - 求解代数方程
   - 逆变换回到时域

### 工程应用
- 控制系统分析
- 电路分析
- 机械振动分析

## 第三章 输入、输出、传递函数与频率响应

### 核心概念
- **传递函数**：系统输出与输入的拉氏变换之比
- **频率响应**：系统对不同频率输入信号的响应特性

### 关键理论
1. **传递函数**
   ```
   G(s) = Y(s)/X(s)
   ```
   - 零点：传递函数分子为零的点
   - 极点：传递函数分母为零的点
   - 稳定性条件：所有极点位于左半平面

2. **频率响应分析**
   - 幅频特性：|G(jω)|
   - 相频特性：∠G(jω)
   - 伯德图：对数频率特性曲线

3. **系统性能指标**
   - 带宽：-3dB频率
   - 谐振峰值：最大幅值
   - 相位裕度：稳定性指标

### 工程应用
- 滤波器设计
- 控制系统校正
- 信号调理

## 第四章 反馈伺服系统

### 核心概念
- **反馈控制**：将输出信号反馈到输入端进行比较和调节
- **伺服系统**：能够精确跟踪给定信号的控制系统

### 关键理论
1. **反馈基本原理**
   - 负反馈：减小误差，提高稳定性
   - 正反馈：增强信号，可能导致振荡
   - 误差信号：e(t) = r(t) - y(t)

2. **典型反馈结构**
   ```
   误差 → 控制器 → 被控对象 → 输出
              ↑              ↓
              └──── 反馈 ←───┘
   ```

3. **性能分析**
   - 稳态误差：系统达到稳态后的误差
   - 暂态响应：系统从初始状态到稳态的过程
   - 稳定性：系统在有界输入下产生有界输出

### 工程应用
- 位置控制系统
- 速度控制系统
- 温度控制系统

## 第五章 互相影响的伺服系统

### 核心概念
- **耦合系统**：多个控制回路之间存在相互影响的系统
- **解耦控制**：消除或减少回路间相互影响的控制方法

### 关键理论
1. **多变量系统**
   - 状态空间表示：ẋ = Ax + Bu
   - 传递函数矩阵：G(s) = C(sI-A)⁻¹B + D
   - 耦合分析：关联矩阵

2. **解耦方法**
   - 前馈解耦：引入补偿器
   - 反馈解耦：状态反馈
   - 对角化：将传递函数矩阵对角化

3. **稳定性分析**
   - 特征值分析
   - 李雅普诺夫方法
   - 鲁棒稳定性

### 工程应用
- 多轴协调控制
- 飞行控制系统
- 机器人控制

## 第九章 平衡运动下的线性系统

### 核心概念
- **平衡点**：系统状态保持不变的点
- **线性化**：在平衡点附近将非线性系统近似为线性系统

### 关键理论
1. **平衡点分析**
   - 平衡点条件：ẋ = 0
   - 平衡点类型：稳定、不稳定、鞍点
   - 相平面分析

2. **线性化方法**
   - 泰勒展开：f(x) ≈ f(x₀) + J(x₀)(x-x₀)
   - 雅可比矩阵：J = ∂f/∂x
   - 线性化系统：δẋ = Aδx

3. **稳定性判据**
   - 特征值实部全部为负：渐近稳定
   - 特征值实部有正：不稳定
   - 李雅普诺夫第一方法

### 工程应用
- 非线性系统分析
- 小扰动分析
- 稳定性设计
