- OpenClaw installation (must be installed on new device first)

## System Requirements
- Python 3.7+

## Troubleshooting

### Import fails with "path not found"
Make sure you're running from the migration package directory.

### Database locked
Close any other programs accessing the database before importing.

### Permission denied
Run as Administrator if needed.

## Rollback
If something goes wrong, the original database is not modified during import. Just re-run import to restore.
