📝 配置教程

部署完成后，如何修改模型和 API 配置

🔧 修改模型配置

打开配置文件，找到 DEFAULT_MODEL= 行：

# Claude 模型
DEFAULT_MODEL=claude-3-opus-20240229  # 最强
DEFAULT_MODEL=claude-3-sonnet-20240229 # 均衡
DEFAULT_MODEL=claude-3-haiku-20240307  # 最快

# DeepSeek 模型
DEFAULT_MODEL=deepseek-chat  # 推荐

# Groq 模型
DEFAULT_MODEL=mixtral-8x7b-32768  # 推荐
DEFAULT_MODEL=llama2-70b-4096     # 强大

🔑 修改 API Key

从官方获取 API Key 后，修改配置文件：

# 获取 API Key
# Claude: https://console.anthropic.com
# OpenAI: https://platform.openai.com
# DeepSeek: https://platform.deepseek.com
# Groq: https://console.groq.com

ANTHROPIC_API_KEY=你的密钥
OPENAI_API_KEY=你的密钥
DEEPSEEK_API_KEY=你的密钥

🔄 重启服务

修改配置后，需要重启服务：

# Windows
cd ~/openclaw
npm start

# WSL/Mac/Linux
cd ~/openclaw
npm start

❓ 常见问题

部署和使用过程中遇到的常见问题

Q: 如何知道当前使用的模型？

A: 查看配置文件中的 DEFAULT_MODEL 配置项

Q: 修改配置后不生效？

A: 确保重启了服务，配置文件修改后必须重启才能生效

Q: 如何获取 API Key？

A: 访问各平台官网注册账号后获取：

  • Claude: https://console.anthropic.com
  • OpenAI: https://platform.openai.com
  • DeepSeek: https://platform.deepseek.com
  • Groq: https://console.groq.com

Q: 脚本运行报错怎么办？

A: 请检查：

  • 是否以管理员身份运行（Windows）
  • 网络连接是否稳定
  • 是否遵守了风险提示
