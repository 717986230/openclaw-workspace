# 蜂群-蚁群混合策略 (Swarm-Hybrid-Strategy)

## 概述

融合蚁群算法 (ACO) 和蜂群算法 (ABC) 的多Agent协作策略，结合两种群智能的优势。

## 核心概念

### 蚁群策略 (Ant Colony)
- **去中心化**：大量简单Agent并行工作
- **信息素机制**：通过环境标记传递信息
- **正反馈**：好的路径会被强化
- **适用**：路径优化、分布式搜索、探索任务

### 蜂群策略 (Bee Colony)
- **分工明确**：工蜂、侦查蜂、跟随蜂
- **摇摆舞通信**：通过直接交流传递资源位置
- **中心协调**：蜂后/仓库作为信息汇聚点
- **适用**：资源采集、任务分配、集中决策

### 混合策略优势
| 特性 | 蚁群 | 蜂群 | 混合策略 |
|------|------|------|----------|
| 探索能力 | ★★★ | ★★ | ★★★ |
| 收敛速度 | ★★ | ★★★ | ★★★ |
| 鲁棒性 | ★★★ | ★★ | ★★★ |
| 决策质量 | ★★ | ★★★ | ★★★ |

## Agent 角色设计

### 1. 侦查Agent (Scout) - 蜂群
- 负责探索新区域/新信息源
- 发现优质资源后返回汇报
- 数量较少，专注于广度

### 2. 工蚁Agent (Worker) - 蚁群
- 大量并行执行采集任务
- 遵循信息素路径
- 简单、快速、数量多

### 3. 评估Agent (Evaluator) - 蜂群
- 对采集结果进行质量评估
- 决定是否值得深入
- 过滤低价值信息

### 4. 协调Agent (Coordinator) - 混合
- 维护全局信息素地图
- 分配任务优先级
- 处理Agent间冲突

### 5. 记忆Agent (Memory) - 支持
- 存储历史最优路径
- 记录资源质量评分
- 提供检索服务

## 信息素机制

### 信息素类型
1. **路径信息素**：标记访问过的资源路径
2. **质量信息素**：标记资源的价值评分
3. **时间信息素**：标记信息的时效性

### 蒸发规则
- 每小时蒸发 10%
- 高质量路径蒸发更慢
- 防止陷入局部最优

## 使用方式

### 启动混合策略
```
/swarm-hybrid launch <任务描述>
```

### 配置参数
```
/swarm-hybrid config --scouts=3 --workers=10 --evaluators=2
```

### 查看状态
```
/swarm-hybrid status
```

## 适用场景

1. **信息收集任务**：多源数据采集与整合
2. **市场研究**：行业动态、竞品分析
3. **问题诊断**：多维度排查问题
4. **创意生成**：发散探索 + 收敛评估

## 注意事项

- Scout 数量不宜过多，避免重复探索
- Worker 需要设置上限，防止资源耗尽
- 定期清理过期信息素，保持地图有效
- Evaluator 评分标准需要任务相关
