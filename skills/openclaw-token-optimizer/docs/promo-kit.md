## GitHub Release Notes (English)

```md
## OpenClaw Token Optimizer v3.0.0

This release expands the optimizer from runtime tuning into **pre-runtime context reduction**.

### Highlights
- Added **Lazy Skill Loading** as **Capability 0**
- Reduced context loading costs by **40–93%** depending on skill library size
- Added references to the companion lazy-loading skill
- Added token savings table for 5 / 10 / 20 skills

### Why this matters
A lot of OpenClaw cost is determined before the real task even starts.
If too many skills are loaded up front, you pay for context that the current task may never need.

This release pushes optimization earlier in the workflow:
1. load less
2. route smarter
3. keep caches warm
4. track budget continuously

### Best fit
- large OpenClaw workspaces
- users with many installed skills
- long-running sessions
- cost-sensitive OpenClaw usage

### Upgrade notes
Lazy loading is now positioned as the **first optimization to apply** before the rest of the runtime improvements.

If you want the biggest immediate win, start there.
```
