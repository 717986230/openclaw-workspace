# Testing Agent Configuration

## Overview

The Testing Agent is responsible for automated test generation, execution, and reporting within the OpenDevin framework.

## Agent Types

### TestAgent

Primary agent for test automation tasks.

**Capabilities:**
- Test generation from code
- Test execution and reporting
- Coverage analysis
- Test maintenance

**Configuration:**
```yaml
agent:
  type: TestAgent
  model: claude-3-sonnet
  
  # Test generation settings
  generation:
    framework: pytest
    style:Arrange-Act-Assert
    include_edge_cases: true
    coverage_target: 80
    
  # Execution settings
  execution:
    parallel: true
    max_workers: 4
    timeout_per_test: 60
    fail_fast: false
    
  # Reporting settings
  reporting:
    formats:
      - junit-xml
      - html
      - json
    output_dir: ./test-results
```

### TestReviewAgent

Agent specialized in test quality review.

**Capabilities:**
- Test code review
- Coverage gap analysis
- Test smell detection
- Test optimization

**Configuration:**
```yaml
agent:
  type: TestReviewAgent
  
  review:
    check_coverage: true
    check_assertions: true
    check_isolation: true
    check_naming: true
    
  recommendations:
    suggest_improvements: true
    suggest_refactors: true
```

## Test Generation

### From Code Analysis

```python
from openclaw.integrations.opendevin import TestGenerator

generator = TestGenerator()

# Generate tests for a module
tests = generator.generate(
    source_path="./src/main.py",
    framework="pytest",
    options={
        "include_edge_cases": True,
        "mock_external": True,
        "coverage_target": 80
    }
)

# Save generated tests
generator.save(tests, output_path="./tests/test_main.py")
```

### From Specification

```python
# Generate tests from requirements
tests = generator.generate_from_spec(
    spec="""
    User authentication endpoint:
    - POST /auth/login
    - Returns JWT token on success
    - Returns 401 on invalid credentials
    - Rate limited to 5 attempts per minute
    """,
    test_type="integration"
)
```

### From Existing Behavior

```python
# Record and generate tests from actual usage
recorder = generator.record_usage("./src/api.py")

# Interact with the system
# ... (recorded actions)

# Generate tests from recordings
tests = recorder.generate_tests()
```

## Test Templates

### Unit Test Template

```python
# templates/unit_test.py.j2
"""
Unit tests for {{ module_name }}
Generated by OpenDevin TestAgent
"""

import pytest
from unittest.mock import Mock, patch
from {{ module_path }} import {{ class_name }}


class Test{{ class_name }}:
    """Test suite for {{ class_name }}"""
    
    @pytest.fixture
    def sut(self):
        """System under test"""
        return {{ class_name }}()
    
    {% for method in methods %}
    def test_{{ method.name }}_{{ scenario }}(self, sut):
        """Test {{ method.name }} with {{ scenario }}"""
        # Arrange
        {{ method.arrange_code | default("# TODO: Setup test data") }}
        
        # Act
        result = sut.{{ method.name }}({{ method.args | default("") }})
        
        # Assert
        {{ method.assert_code | default("assert result is not None") }}
    {% endfor %}
```

### Integration Test Template

```python
# templates/integration_test.py.j2
"""
Integration tests for {{ feature_name }}
"""

import pytest
from fastapi.testclient import TestClient
from {{ app_module }} import app


@pytest.fixture
def client():
    """Test client fixture"""
    return TestClient(app)


@pytest.fixture
def db_session():
    """Database session fixture"""
    # Setup
    session = create_test_session()
    yield session
    # Teardown
    session.close()


class Test{{ feature_name }}Integration:
    """Integration test suite for {{ feature_name }}"""
    
    def test_full_flow(self, client, db_session):
        """Test complete {{ feature_name }} flow"""
        # Create
        response = client.post("/{{ endpoint }}", json={{ create_data }})
        assert response.status_code == 201
        
        # Read
        item_id = response.json()["id"]
        response = client.get(f"/{{ endpoint }}/{item_id}")
        assert response.status_code == 200
        
        # Update
        response = client.put(f"/{{ endpoint }}/{item_id}", json={{ update_data }})
        assert response.status_code == 200
        
        # Delete
        response = client.delete(f"/{{ endpoint }}/{item_id}")
        assert response.status_code == 204
```

## Test Execution

### Local Execution

```python
from openclaw.integrations.opendevin import TestRunner

runner = TestRunner()

# Run all tests
result = runner.run(
    test_path="./tests",
    options={
        "parallel": True,
        "coverage": True,
        "verbose": True
    }
)

print(f"Passed: {result.passed}, Failed: {result.failed}")
print(f"Coverage: {result.coverage}%")
```

### Container Execution

```python
# Run tests in isolated container
result = runner.run_in_container(
    test_path="./tests",
    container_config={
        "image": "python:3.11",
        "setup": ["pip install -r requirements.txt"],
        "volumes": {
            "./src": "/workspace/src",
            "./tests": "/workspace/tests"
        }
    }
)
```

### Distributed Execution

```python
# Run tests across multiple nodes
result = runner.run_distributed(
    test_path="./tests",
    nodes=[
        {"host": "node1.example.com", "workers": 4},
        {"host": "node2.example.com", "workers": 4}
    ],
    strategy="load_balance"
)
```

## Coverage Analysis

### Coverage Collection

```python
from openclaw.integrations.opendevin import CoverageAnalyzer

analyzer = CoverageAnalyzer()

# Analyze coverage
coverage = analyzer.analyze(
    source_path="./src",
    test_path="./tests",
    options={
        "branch_coverage": True,
        "exclude_patterns": ["*/migrations/*", "*/tests/*"]
    }
)

# Get coverage report
report = coverage.get_report()
print(f"Line coverage: {report.line_coverage}%")
print(f"Branch coverage: {report.branch_coverage}%")
```

### Coverage Reports

```python
# Generate various report formats
coverage.generate_report(
    format="html",
    output_path="./coverage/html"
)

coverage.generate_report(
    format="xml",
    output_path="./coverage/cobertura.xml"
)

coverage.generate_report(
    format="json",
    output_path="./coverage/coverage.json"
)
```

### Coverage Gates

```yaml
# Coverage quality gates
coverage_gates:
  minimum:
    line: 80
    branch: 70
    function: 90
    
  # Fail build if below threshold
  fail_if_below: true
  
  # Delta from previous
  max_degradation: -5
```

## Test Maintenance

### Test Refactoring

```python
from openclaw.integrations.opendevin import TestRefactorer

refactorer = TestRefactorer()

# Refactor tests
refactored = refactorer.refactor(
    test_path="./tests",
    changes=[
        {"type": "extract_fixture", "pattern": "duplicate_setup"},
        {"type": "parameterize", "pattern": "similar_tests"},
        {"type": "improve_naming", "pattern": "test_*"}
    ]
)
```

### Test Cleanup

```python
# Remove obsolete tests
refactorer.remove_obsolete(
    test_path="./tests",
    source_path="./src",
    remove_skipped=True,
    remove_unreferenced=True
)

# Detect and fix flaky tests
flaky = refactorer.detect_flaky(
    test_path="./tests",
    runs=10,
    threshold=0.1  # 10% failure rate
)
```

## Best Practices

### 1. Test Generation

- Generate tests incrementally
- Review generated tests before saving
- Customize templates for project style
- Include edge cases and error scenarios

### 2. Test Execution

- Run tests in isolation
- Use parallel execution for speed
- Implement proper cleanup
- Set appropriate timeouts

### 3. Coverage Management

- Set realistic coverage targets
- Focus on critical paths
- Monitor coverage trends
- Don't sacrifice quality for coverage

### 4. Test Maintenance

- Regular test reviews
- Remove obsolete tests
- Refactor duplicated code
- Fix flaky tests promptly

## Integration with CI/CD

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
          
      - name: Run OpenDevin Tests
        run: |
          openclaw opendevin test \
            --path ./tests \
            --coverage \
            --report junit-xml \
            --output ./test-results
            
      - name: Upload Coverage
        uses: codecov/codecov-action@v3
        with:
          files: ./coverage/cobertura.xml
```
