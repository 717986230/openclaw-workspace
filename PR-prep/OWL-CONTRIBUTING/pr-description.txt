## PR Title
docs: add CONTRIBUTING.md for community onboarding

## PR Body

### What this PR does

Adds a comprehensive `CONTRIBUTING.md` to the OWL repository. Currently, OWL has no contribution guide — this PR fills that gap to help onboard new contributors.

### Why it matters

OWL is a high-impact project (#1 on GAIA, NeurIPS 2025) with an active community. The parent CAMEL-AI org has contribution guidelines, but OWL itself has no `CONTRIBUTING.md`. New contributors have no clear path to:

- Set up their development environment
- Understand the branching model
- Know code style requirements
- Navigate AI-generated code disclosure requirements

This PR solves that.

### What the guide covers

- Development environment setup (Python 3.10–3.12, uv, pytest)
- Branching strategy (main/develop/feat*/fix*/docs*)
- Code style (ruff, black, mypy, pre-commit)
- Testing and GAIA evaluation
- **AI-generated code disclosure policy** (required by CAMEL-AI org)
- PR checklist and Conventional Commits format
- Community links (Discord, X, WeChat, Reddit)
- License reference (Apache 2.0)
