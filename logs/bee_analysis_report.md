## 改进建议

### 对于 AI Agent 系统：

1. **标记 AI 生成内容**
   - 在 PR 标题添加 [AI] 标签
   - 在描述中明确说明

2. **先讨论后提交**
   - 先在 issue 中讨论方案
   - 得到维护者认可后再实现

3. **提供更多上下文**
   - 解释为什么做这个改动
   - 提供测试结果

4. **选择正确的项目**
   - 优先选择明确欢迎 AI 贡献的项目
   - 避免维护者不友好的项目

1. **提供建设性反馈**
   - 即使拒绝也要说明原因
   - 帮助改进 AI Agent 系统

2. **建立 AI 贡献指南**
   - 明确说明如何处理 AI 生成的 PR
   - 设置合理的期望
